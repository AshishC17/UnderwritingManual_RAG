New Customer Full Underwriting Process

This flowchart describes the full underwriting stage that follows prequalification. The process starts at Continue Application from Prequalification, moves to Determine Channel, then to Run Full Underwriting Policy & Credit Checks, which feeds the Rule Result? decision point. Rule Result? has four outcomes: Pass, NOAA, Manual Review, and RFAI. On Pass the application proceeds to Run Scoring & Affordability → Line, then Fraud & Compliance Checks, then the Clear? decision. If Clear? is Yes the application reaches Present Approved / Counteroffer and then the Customer Accepts? decision; if Clear? is No it is routed to Manual Review. If Customer Accepts? is Yes the application proceeds to Intraday Account Review and then to the All Required Verifications Complete? decision; if No it reaches Expire Application. If All Required Verifications Complete? is Yes the application reaches Ready to Fund, the successful terminal state; if No it is routed to Manual Review. On NOAA the application goes to Assign Applicable NOAA, then Send Notification, then Expire Application. On Manual Review the application goes to Manual Review, which leads to the Reviewer Outcome? decision, whose branches are approve to Approved, counter to Counteroffer, NMI to Need More Information (NMI), and decline to Expire Application. On RFAI, and from Need More Information (NMI) once resolved, the application reaches Evidence / Verification, which loops back to Run Full Underwriting Policy & Credit Checks for re-evaluation. Terminal states are Ready to Fund, Approved, Counteroffer, and Expire Application.

Decision paths:
- Continue Application from Prequalification --> Determine Channel
- Determine Channel --> Run Full Underwriting Policy & Credit Checks
- Run Full Underwriting Policy & Credit Checks --> Rule Result?
- Rule Result? --Pass--> Run Scoring & Affordability → Line
- Rule Result? --NOAA--> Assign Applicable NOAA
- Rule Result? --Manual Review--> Manual Review
- Rule Result? --RFAI--> Evidence / Verification
- Run Scoring & Affordability → Line --> Fraud & Compliance Checks
- Fraud & Compliance Checks --> Clear?
- Clear? --Yes--> Present Approved / Counteroffer
- Clear? --No--> Manual Review
- Present Approved / Counteroffer --> Customer Accepts?
- Customer Accepts? --Yes--> Intraday Account Review
- Customer Accepts? --No--> Expire Application
- Intraday Account Review --> All Required Verifications Complete?
- All Required Verifications Complete? --Yes--> Ready to Fund
- All Required Verifications Complete? --No--> Manual Review
- Assign Applicable NOAA --> Send Notification
- Send Notification --No--> Expire Application
- Manual Review --> Reviewer Outcome?
- Reviewer Outcome? --approve--> Approved
- Reviewer Outcome? --counter--> Counteroffer
- Reviewer Outcome? --NMI--> Need More Information (NMI)
- Reviewer Outcome? --decline--> Expire Application
- Need More Information (NMI) --resolved--> Evidence / Verification
- Evidence / Verification --> Run Full Underwriting Policy & Credit Checks
