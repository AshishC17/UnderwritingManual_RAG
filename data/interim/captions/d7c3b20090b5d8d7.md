New Customer Pre-Qual Process

This flowchart describes the prequalification stage for a new customer application. The Decision Engine Receives App, then the system moves to Determine Channel, then to Run Prescreen Prequalification Checks, which feeds the Rule Result? decision point. Rule Result? has four outcomes: Pass, NOAA, Manual Review, and RFAI. On Pass the application proceeds to Assign Line, then Display Offer, then the Customer Accepts? decision; if the customer accepts, the application reaches Continue Application → Full Underwriting, and if not it reaches Expire Application. On NOAA the application goes to Assign Applicable NOAA, then Send Notification, then Expire Application. On Manual Review the application goes to Manual Review and then to the Reviewer Outcome? decision, whose branches are approve to Approved, counter to Counteroffer, NMI to Need More Information (NMI), and decline to Send Notification. On RFAI the application goes directly to Need More Information (NMI). Need More Information (NMI) loops back to Run Prescreen Prequalification Checks once info received, allowing the application to be re-evaluated. Terminal states are Continue Application → Full Underwriting, Approved, Counteroffer, and Expire Application.

Decision paths:
- Decision Engine Receives App --> Determine Channel
- Determine Channel --> Run Prescreen Prequalification Checks
- Run Prescreen Prequalification Checks --> Rule Result?
- Rule Result? --Pass--> Assign Line
- Rule Result? --NOAA--> Assign Applicable NOAA
- Rule Result? --Manual Review--> Manual Review
- Rule Result? --RFAI--> Need More Information (NMI)
- Assign Line --> Display Offer
- Display Offer --> Customer Accepts?
- Customer Accepts? --Yes--> Continue Application → Full Underwriting
- Customer Accepts? --No--> Expire Application
- Assign Applicable NOAA --> Send Notification
- Send Notification --> Expire Application
- Manual Review --> Reviewer Outcome?
- Reviewer Outcome? --approve--> Approved
- Reviewer Outcome? --counter--> Counteroffer
- Reviewer Outcome? --NMI--> Need More Information (NMI)
- Reviewer Outcome? --decline--> Send Notification
- Need More Information (NMI) --info received--> Run Prescreen Prequalification Checks
